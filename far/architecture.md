# Architektura

## Použité nástroje

| Nástroj | Popis | Instalace |
| --- | --- | --- |
| Ghidra | GUI disassembler (doporučeno) | Stáhnout z [ghidra-sre.org](https://ghidra-sre.org) |
| radare2 | Terminálový disassembler | `sudo apt install radare2` |
| nasm | Assembler pro `.asm` → `.bin` | `sudo apt install nasm` |
| hexedit | Hex editor v terminálu | `sudo apt install hexedit` |
| dd | Terminálový nástroj pro binární patchování | předinstalovaný |
| python3 | Pro skripty jako `bios_port_search.py` | předinstalovaný |
